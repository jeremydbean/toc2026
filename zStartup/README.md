# Archived Startup Scripts

The files below `zStartup/` preserve historical machine-specific deployment
scripts. They contain retired repository names, permissive file modes,
hard-coded paths, and process-management assumptions. They are not supported
installation or launch instructions and should not be run on a current host.

Use instead:

- `docker compose up --build -d` for the recommended deployment
- root `../startup.sh` for a native auto-restarting server
- `../scripts/setup_linux.sh`, `../scripts/setup_mac.sh`, or
  `../scripts/setup_windows.ps1` for current prerequisite helpers
- `../wiki/hosting-guide.md` for complete installation and operation procedures

The archive remains only for project history and migration reference.
